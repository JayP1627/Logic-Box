->This project is a menu driven program app.

it gives 3 option of 1.pattern generator
                     2.Number Analyzer 
                     3.exit .
                     
i used while loop , for loop, nested for loop, if-else  statement , and  Match-case  Also,
first i start from while loop , which is look like infinite loop until you choose option 3 of exit , i used break keyword for exiting the loop in case 3.

-> nested for loop is used for making the patterns, for the program of pattern generator , which takes input of rows and make a right angle triangle of *.

-> then for number analyzer ,we get user input of start and stop of range, 
as it gives even and odd numbers and also give the sum of them.
i used simple if else statement for find even and odd number and put the if-else in for loop , for finding it for given range of all number.
And also used Assignment operator += , for doing the sum of all numbers.

-> In last i make the default case for match-case , for the user who accidently enter the wrong choise.
